# Распространение исходного кода

Для каждого выпуска я фиксирую коммит, параметры сборки и версии зависимостей и прикладываю тексты лицензий сторонних компонентов, которые реально входят в выпуск.

- Приложение ссылается на исходники своей версии, а не всегда на текущую ветку `main`.
- Сайт gram.lovlydev.ru показывает ссылку на коммит, из которого он собран, как требует раздел 13 AGPLv3 для использования по сети.
- Исходники и уведомления сторонних компонентов предоставляются по их собственным лицензиям.
- Ключи подписи обновлений, приватные ключи кошельков и фразы восстановления никогда не публикуются.
