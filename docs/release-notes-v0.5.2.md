# Gramix 0.5.2

В уведомлениях Telegram Watchtower показывает полный адрес кошелька в формате EQ. Нажмите на адрес, чтобы скопировать его. Подтверждение содержит дату и время операции в часовом поясе компьютера с указанием смещения. Время остаётся интерактивным в Telegram.

В ленте Watchtower у операции есть отдельная иконка направления, название и строка с датой. Сумма перевода вынесена вправо.

Для Windows доступен установщик x64, для Linux amd64 — deb и AppImage. Контрольные суммы опубликованы в `SHA256SUMS.txt`. Фоновый бот работает в приложении для Windows.
