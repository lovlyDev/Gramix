# Gramix 0.6.1

- На дальнем масштабе большой граф объединяет адреса в группы с количеством участников. Нажмите на группу для приближения. Поиск по адресу ведёт к отдельному узлу.
- Граф ограничивает количество связей в текущей области просмотра, а при загрузке обновляет раскладку пакетами. В SVG сохраняется полная выбранная история.
- Щелчок мышью по графу больше не обводит всё полотно. При навигации через Tab индикатор фокуса сохраняется. Enter открывает карточку адреса.

## Установка

Windows — установщик NSIS x64. Linux — пакеты deb и AppImage для amd64. Контрольные суммы приведены в `SHA256SUMS.txt`.

## Ограничения

Загрузка истории зависит от внешнего API. Для генерации адресов доступны CPU и поддерживаемый Vulkan. CUDA и HIP в установщики не входят.
