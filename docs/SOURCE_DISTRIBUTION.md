# Source Distribution

For each release I record the commit, build options, and dependency versions, and I attach the license texts of third-party components that the release actually contains.

- The application links to the source of its exact version, not unconditionally to the current `main` branch.
- The gram.lovlydev.ru website shows a link to the commit it was built from, as section 13 of AGPLv3 requires for network use.
- Third-party source and notices are provided according to their own licenses.
- Update-signing keys, wallet private keys, and recovery phrases are never published.
