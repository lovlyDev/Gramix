# Gramix 0.6.0

Я добавил граф переводов в Sentinel. Введите публичный адрес Mainnet, чтобы посмотреть его связи и историю переводов в приложении или на сайте.

- Дерево показывает ветви адресов, паутина показывает поперечные связи. Граф можно перемещать, масштабировать с помощью Ctrl и колеса мыши и открыть на весь экран.
- «Поток средств» группирует подтверждённые переводы по отправителям и получателям. Толщина линии пропорциональна сумме, щелчок открывает операции по этому направлению.
- «Активность по времени» показывает входящие и исходящие операции по часам или дням. Выделите интервал мышью, чтобы отфильтровать остальные виды.
- Доступные фильтры зависят от вида графа и загруженных переводов. Минимальная сумма применяется в «Потоке средств».
- Настроенную выборку можно сохранить как SVG или открыть по ссылке. Граф использует общую тему Gramix.

## Установка

Windows — установщик NSIS для x64. Linux — пакет deb и AppImage для amd64. Контрольные суммы перечислены в `SHA256SUMS.txt`.

## Ограничения

Граф показывает историю, которую вернул API. Загрузка больших историй зависит от его доступности и лимитов. Ссылка загружает свежие данные. Для вычисления адресов доступны CPU и поддерживаемый Vulkan. CUDA и HIP в установщики не входят.
