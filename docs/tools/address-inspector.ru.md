# Проверка адреса

[English](address-inspector.md) | Русский

Проверка адреса разбирает raw и friendly GRAM-адреса. Сама проверка выполняется без сети.

```text
gramix address inspect EQAs9VlT6S776tq3unJcP5Ogsj-ELLunLXuOb1EKcOQi4wJB
gramix address inspect 0:2cf55953e92efbeadab7ba725c3f93a0b23f842cbba72d7b8e6f510a70e422e3 --json
```

Проверяются длина, алфавит, CRC16, теги bounceable/testnet, workchain и 256-битный хеш. На выходе — канонический raw и варианты bounceable и non-bounceable того же адреса. В raw-адресе нет флага сети, поэтому его friendly-варианты используют mainnet. Это кодировка адреса, а не доказательство существования аккаунта. Для повреждённого адреса команда возвращает ненулевой код выхода.

В приложении и на сайте эта проверка находится на странице «Проверка адреса», с кнопками копирования и QR-кодом публичного адреса. Ссылки вида `https://gram.lovlydev.ru/address/<адрес>` открывают её сразу.

Отдельная кнопка «Запросить состояние аккаунта» отправляет в OpenTonAPI только проверенный публичный raw-адрес: `testnet.tonapi.io` для testnet, иначе `tonapi.io`. Ответ помечается источником и временем; баланс показывается в GRAM, точное значение — в подсказке. У запроса есть тайм-аут 10 секунд, ограничение размера ответа, обработка HTTP 429 и минимальный интервал. Ответ не кэшируется и сбрасывается при новом вводе.
