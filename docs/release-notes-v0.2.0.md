# Gramix 0.2.0

Я выпускаю Gramix — так теперь называется VANTIX. Вместо одного генератора адресов это набор из 12 инструментов для сети GRAM, а те же инструменты работают на сайте [gram.lovlydev.ru](https://gram.lovlydev.ru).

## Скачать

- Windows: `Gramix_0.2.0_x64-setup.exe` (NSIS).
- Linux: `Gramix_0.2.0_amd64.deb` или `Gramix_0.2.0_amd64.AppImage`.
- Контрольные суммы находятся в `SHA256SUMS.txt`.

## Что нового

- Новый интерфейс: верхняя навигация по разделам «Кошельки», «Блокчейн», «Разработка», поиск по адресу, хэшу, BOC и ссылкам эксплореров, главная страница со сводкой и тёмная, OLED и светлая темы.
- Инструменты: поиск адреса, новый кошелёк, проверка кошелька, проверка адреса, разбор транзакций, BOC Explorer, контракты и get-методы, Contract Vanity, Sandbox, Builder для Tolk, Benchmark и Developer CLI.
- Суммы показываются в GRAM с разделением разрядов; точное значение — в подсказке.
- Сайт gram.lovlydev.ru: те же инструменты в браузере, кроме Developer CLI и ввода своей фразы восстановления. Прямые ссылки вида `/address/…`, `/tx/…`, `/contract/…`.
- Лицензия — AGPL-3.0-only.

## Переход с VANTIX

- При первом запуске Gramix копирует сохранённые кошельки и найденные адреса из папки VANTIX. Старая папка не удаляется.
- Gramix устанавливается как отдельное приложение: после проверки данных VANTIX 0.1.0 можно удалить.
- Настройки интерфейса и история Benchmark начинаются заново.
- Для CLI переменные называются `GRAMIX_WALLET_PASSWORD` и `GRAMIX_RESOURCE_DIR`; старые `VANTIX_*` по-прежнему работают.

## Телеметрия

- Приложение ничего не отправляет: кода статистики в нём нет, и CI проверяет это при каждой сборке.
- Сайт собирает статистику только после согласия посетителя. Фразы, ключи и файлы не отправляются никогда. Подробности — на странице «Конфиденциальность» сайта.

## Известные ограничения

- CUDA и HIP есть в исходниках, но их модули не входят в установщики: работа на картах NVIDIA и AMD не проверена. На таких картах доступен Vulkan Compute при поддержке драйвером, CPU остаётся запасным режимом.
- Ускорение GPU реализовано для 12-словной схемы. Для 24 слов используется CPU.
- На сайте поиск адреса и Benchmark работают только на CPU в Web Worker и заметно медленнее приложения; 24-словная схема в браузере очень медленная.
- Совместная работа нескольких физических GPU не подтверждена аппаратной проверкой.
- Установщик Windows не подписан сертификатом издателя; SmartScreen может показать предупреждение.
