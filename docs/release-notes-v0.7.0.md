# Gramix 0.7.0

- В настройках Telegram можно задать отдельное правило Watchtower для каждого наблюдаемого адреса. Укажите направление, типы событий и минимальную сумму в GRAM. Уведомление показывает имя кошелька и правило, по которому оно сработало. Кнопка «Открыть на графе» ведёт к событию.
- В приложении можно сохранить разбор с адресом, раскладкой, фильтрами, раскрытыми ветвями и личными заметками. При повторном открытии Gramix показывает новые связи по доступной истории. Разборы и заметки хранятся локально.
- В графе появилась функция «Сравнить периоды». Она показывает число подтверждённых переводов, входящие и исходящие суммы GRAM, новые адреса и крупнейших получателей.

## Установка

Windows — установщик NSIS x64. Linux — пакеты deb и AppImage для amd64. Контрольные суммы приведены в `SHA256SUMS.txt`.

## Ограничения

Фоновый бот Telegram доступен в Windows. Результаты сравнения зависят от доступной истории внешнего API. Для поиска адресов доступны CPU и поддерживаемый Vulkan. CUDA и HIP в установщики не входят.
