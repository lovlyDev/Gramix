# Gramix 0.5.0

В этом выпуске я добавил Sentinel для мониторинга публичных адресов GRAM и анализа сообщений до отправки.

- Watchtower показывает события, а Wallet Portfolio объединяет балансы, Jettons и NFT нескольких адресов. История оценки накапливается при обновлениях. Операции можно выгрузить в CSV.
- Contract Watch следит за состоянием контракта. Contract Diff сравнивает код, storage и ссылки на библиотеки между двумя блоками. Для сравнения ABI можно выбрать два файла JSON.
- Transaction Guardian выполняет сообщение в локальном Sandbox с публичным состоянием Mainnet. Граф показывает получателей, комиссии и результаты исполнения. Симуляция не гарантирует безопасность перевода.
- В приложении для Windows можно подключить своего Telegram-бота, выбрать события и настроить запуск при входе в Windows. Для доставки компьютер должен быть включён и иметь доступ к сети.

## Установка

Windows — установщик x64 NSIS. Linux — пакет deb и AppImage для amd64. Контрольные суммы перечислены в `SHA256SUMS.txt`.

## Ограничения

Доступность истории и котировок зависит от внешних API. Доставка в личный чат и запуск после входа в Windows требуют проверки с токеном владельца. Для вычислений доступны CPU и поддерживаемый Vulkan; CUDA и HIP в установщики не включены.
