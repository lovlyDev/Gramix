# Gramix 0.5.1

- Watchtower и Wallet Portfolio сохраняют выбранный кошелёк, период, оценку активов и ленту при переходах между инструментами и сворачивании приложения в трей. При полном выходе сеанс завершается.
- У открытого раздела сохраняется минутный интервал обновления. Скрытый раздел завершает текущую загрузку и пропускает плановые запросы.
- Watchtower объединяет управление адресами, события и Telegram. В Portfolio доступны оценка, распределение активов и экспорт истории стоимости в CSV.
- Contract Watch, Contract Diff и Guardian также сохраняют ввод и результаты при навигации.
- Подсказки графа сообщений, пустой ленты и уведомлений Telegram используют стиль второстепенного текста.
- Клиенты API адресов, контрактов и транзакций указывают версию установленной сборки в запросах.

Для Windows доступен установщик x64, для Linux amd64 — deb и AppImage. Контрольные суммы указаны в `SHA256SUMS.txt`. Для обновления данных нужен доступ к внешним API.
